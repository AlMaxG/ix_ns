# iXBT News Feed — Автономная веб-страница

> **Никакого npm, Node.js или серверной части!**  
> Приложение представляет собой **одну автономную веб-страницу** (`index.html`) на чистом HTML, CSS и JavaScript.

## Как запустить

1. Просто откройте файл `index.html` в любом современном браузере (двойным кликом или через `Файл` → `Открыть` в Chrome, Firefox, Safari, Edge).
2. Загрузка свежих новостей с [ixbt.com/news](https://www.ixbt.com/news/) начнётся автоматически сразу после открытия.

## Возможности

- **Полные статьи, а не только анонсы**: загружает и отображает полный текст новостей, цитаты и иллюстрации.
- **Умная догрузка по датам**: если на главной странице ixbt.com/news новостей меньше выбранного количества, ссылка автоматически дополняется предыдущей датой вида `https://www.ixbt.com/news/ГГГГ/ММ/ДД` для добора недостающих публикаций.
- **Тёмная тема iXBT**: цвета, типографика и логотип в точности соответствуют тёмной теме сайта ixbt.com (`#12131b`, `#181a2e`, синие заголовки `#5287c6`, бейджи `#32386e`).
- **Кнопка «Обновить»**: быстрое обновление ленты в любой момент.
- **Настройка количества новостей**: выбор 5, 10, 15, 20, 25, 30 или любого другого числа статей (сохраняется в браузере).
- **Настройка ширины ленты**: готовые пресеты (узкая, стандарт, широкая, на весь экран) и плавный ползунок от 640px до 1600px (сохраняется в браузере).
- **Автономность**: работает полностью в браузере клиента без каких-либо сторонних серверов.
